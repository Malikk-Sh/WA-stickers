# WA Stickers

Android-приложение для создания обычных и анимированных наборов стикеров WhatsApp прямо на телефоне.

## Что умеет

- отдельные черновики для режимов **Фото** и **Анимация**;
- выбор от 3 до 30 файлов в набор;
- фотографии, GIF, animated WebP и видео;
- адаптивная сетка медиа, изменение порядка файлов и выбор обложки набора;
- альтернативные accessibility-действия для перемещения элементов без drag-жеста;
- выбор фрагмента для длинных видео с сохранением trim-настроек;
- локальная конвертация без загрузки медиа на сервер;
- статические стикеры 512×512 WebP с учётом лимита WhatsApp;
- анимированные стикеры с адаптивными профилями качества;
- прогресс обработки по каждому файлу, повтор ошибок и остановка обработки;
- создание набора из уже готовых стикеров при частично успешной обработке;
- сохранённые наборы с фильтрами, поиском, переименованием, дублированием, удалением, деталями и повторным добавлением в WhatsApp;
- очистка недоступных сохранённых наборов;
- темы **Системная / Светлая / Тёмная**, компактный режим и настройки качества анимации;
- сохранение и восстановление черновиков;
- добавление готового набора через официальный WhatsApp sticker-pack intent.

## Интерфейс

Основной сценарий разделён на четыре постоянные вкладки:

1. **Создать** — режим, название и выбор исходных файлов.
2. **Медиа** — сетка файлов, порядок, обложка и детали.
3. **Сборка** — прогресс, ошибки, повтор, отмена и финализация.
4. **Наборы** — сохранённые локальные наборы и действие **«В WhatsApp»**.

Настройки открываются через кнопку ⚙ в верхней части приложения. Меню **⋮** контекстное: на каждой вкладке оно показывает только относящиеся к текущей задаче действия — управление черновиком, медиа, сборкой или сохранёнными наборами, а также помощь и информацию о приложении там, где это уместно.

## Как собрать APK

### Через GitHub Actions

После каждого push в `main` запускается workflow **Android build**: архитектурные guards, lint, JVM-тесты, debug APK, проверочная сборка release-варианта и instrumentation-тесты на Android API 35.

1. Откройте вкладку **Actions** в репозитории.
2. Выберите последний успешный запуск **Android build**.
3. Внизу страницы скачайте artifact **WA-Stickers-debug-apk**.
4. Распакуйте архив и установите `app-debug.apk` на Android-телефон.

CI собирает release-вариант как отдельную проверку компиляции, но не публикует и не подписывает его. Для распространяемого release APK нужен ваш закрытый signing keystore; ключи подписи не должны храниться в репозитории.

### Через Android Studio

1. Клонируйте репозиторий.
2. Откройте корневую папку проекта в Android Studio.
3. Используйте JDK 17.
4. Если IDE просит выбрать Gradle, используйте Gradle 8.9.
5. Запустите приложение на телефоне или соберите APK через **Build > Build APK(s)**.

## Использование

1. На вкладке **Создать** выберите **Фото** или **Анимация**, задайте название и добавьте 3–30 файлов.
2. На вкладке **Медиа** проверьте порядок и обложку. Для длинного видео при необходимости настройте фрагмент.
3. Перейдите в **Сборку** и запустите обработку. Неудачные файлы можно повторить отдельно, не обрабатывая готовые заново.
4. После финализации добавьте набор в WhatsApp или откройте его во вкладке **Наборы**.

## Технические детали

- package: `com.malikksh.wastickers`;
- minSdk: 24;
- targetSdk: 35;
- JDK: 17;
- статические стикеры: WebP, 512×512, до 100 КБ;
- tray icon: PNG, 96×96, до 50 КБ;
- `ContentProvider` authority: `${applicationId}.stickercontentprovider`;
- conversion pipeline использует FFmpegKit и native WebP для анимированных WebP.

Приложение не запрашивает доступ в интернет. Пользовательские медиа обрабатываются локально на устройстве; выбранные файлы читаются через Android document/content URI flow.
