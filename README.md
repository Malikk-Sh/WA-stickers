# WA Stickers

Android-приложение для создания наборов стикеров WhatsApp из обычных фотографий.

## Что умеет

- выбор от 3 до 30 фотографий;
- обработка полностью на телефоне, без загрузки фото на сервер;
- сохранение фотографии целиком без удаления фона;
- без белой обводки;
- автоматическое приведение к 512×512;
- конвертация в WebP и сжатие до лимита WhatsApp;
- создание иконки набора 96×96;
- кнопка **«Добавить в WhatsApp»** через официальный sticker-pack intent;
- хранение нескольких последних созданных наборов.

## Как собрать APK

### Через GitHub Actions

После каждого push в `main` запускается workflow **Android build**.

1. Откройте вкладку **Actions** в репозитории.
2. Выберите последний успешный запуск **Android build**.
3. Внизу страницы скачайте artifact **WA-Stickers-debug-apk**.
4. Распакуйте архив и установите `app-debug.apk` на Android-телефон.

### Через Android Studio

1. Клонируйте репозиторий.
2. Откройте корневую папку проекта в Android Studio.
3. Используйте JDK 17.
4. Если IDE просит выбрать Gradle, используйте Gradle 8.9.
5. Запустите приложение на телефоне или соберите APK через **Build > Build APK(s)**.

## Использование

1. Введите название набора.
2. Нажмите **«Выбрать фото»**.
3. Выберите от 3 до 30 изображений.
4. Нажмите **«Создать набор стикеров»**.
5. После обработки нажмите **«Добавить в WhatsApp»**.
6. Подтвердите добавление набора в WhatsApp.

## Технические детали

- package: `com.malikksh.wastickers`
- minSdk: 24
- targetSdk: 35
- статические стикеры: WebP, 512×512, не более 100 КБ;
- tray icon: PNG, 96×96, не более 50 КБ;
- `ContentProvider` authority: `${applicationId}.stickercontentprovider`.

Проект не запрашивает доступ в интернет. Фотографии читаются через Android Storage Access Framework и преобразуются локально.
